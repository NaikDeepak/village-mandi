  <files>functions/src/index.ts</files>
  <action>
    Implement 'beforeUserSignedIn' using firebase-functions/v2/identity.
    Logic:
    1. Extract phone number from event.
    2. Query Postgres via Prisma.
    3. If status is PENDING, throw HttpsError('permission-denied', 'ACCOUNT_PENDING').
    4. If status is REJECTED, throw HttpsError('permission-denied', 'ACCOUNT_REJECTED').
    5. If not found, treat as PENDING.
    6. Return custom claims including role and status.
  </action>
  <verify>Build functions successfully</verify>

</task>
